# EDA (Exploratory Data Analysis) Checklist

## 1. **Data Overview**
- Shape (rows, columns)
- Data types
- Basic info

## 2. **Missing Values**
- Identify null percentages
- Visualize missing patterns
- Decide: drop or impute?

## 3. **Univariate Analysis** (Individual features)
- Numerical: mean, median, std, min, max, quartiles
- Categorical: value counts, unique values
- Distributions (histograms, box plots)
- Outliers

## 4. **Bivariate Analysis** (Feature relationships)
- Correlation matrix (numerical features)
- Feature vs Target relationships
- Categorical features vs Target

## 5. **Data Quality Checks**
- Duplicate rows
- Inconsistent formats
- Extreme values

## 6. **Target Variable Analysis**
- Class balance (for classification)
- Distribution shape
